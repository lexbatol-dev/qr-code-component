### What I learned

This project helped me put several HTML and CSS concepts into practice.

- **Semantic HTML:** I used elements such as `<main>`, `<h1>` and `<footer>` to give the page a meaningful structure.
- **Flexbox:** I used Flexbox to centre the card on the page. I also used `flex-grow` on `<main>` so the footer stays at the bottom of the screen.
- **The box model:** I used `box-sizing: border-box` so element sizes are more predictable, especially when combining padding with a maximum width.
- **Responsive images:** I learned how to stop an image from overflowing its container, and how `display: block` removes the small gap under an image:

  ```css
  img {
    width: 100%;
    display: block;
  }
  ```

- **CSS custom properties:** I used CSS variables for the challenge's colour palette, which makes the styles easier to maintain.

### AI Collaboration

I used Claude and ChatGPT as learning and debugging companions throughout this project. Rather than asking AI to generate the whole solution, I used it to:

- Understand HTML and CSS concepts.
- Think through layout decisions before implementing them.
- Investigate and debug styling issues.
- Review my HTML and CSS for possible improvements.
- Discuss accessibility and responsive design best practices.

This approach helped me understand the reasoning behind my code instead of simply copying it.
